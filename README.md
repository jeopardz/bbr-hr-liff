# BBR HR — LIFF (หน้า check-in GPS + ลงทะเบียน)

หน้า static สำหรับ LINE LIFF ของระบบ HR พนักงาน BBR
เสิร์ฟผ่าน GitHub Pages (n8n /webhook/ ใส่ sandbox CSP ทำให้ LIFF SDK ใช้ไม่ได้)

ไม่มีความลับในนี้ — LIFF_ID กับ n8n API URL เป็นค่า public
ความปลอดภัยอยู่ที่การ verify LINE ID token ฝั่ง server (n8n engine)
